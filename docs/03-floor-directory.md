# ทำเนียบชั้น ห้องสำคัญ และจุดเชื่อมต่อ VR Tour (B1 – 11F)

อ้างอิงจาก **แผนผังเส้นทางหนีไฟจริงชั้น 1–7 (`references/floorplans/floor_01..07.jpg`)**, **Informatics 360 VR Tour (`page_6718`)** และฐานข้อมูลห้องเรียนของคณะวิทยาการสารสนเทศ ม.บูรพา

* **ทิศทางอ้างอิงตามเข็มทิศในแปลนจริง (`1 บล็อก = 1 เมตร`):**
  * **เหนือ (`-Z`):** ด้านหน้าทางเข้าหลัก, หลังคาโค้ง Podium, ทางลาดผู้พิการ
  * **ตะวันออก (`+X`):** ฝั่งถนนเฟื้องฟ้า
  * **ใต้ (`+Z`):** แกนลิฟต์โดยสาร 3 ตัว + ลิฟต์ดับเพลิง 1 ตัว + บันไดหลัก + ห้องน้ำ
  * **ตะวันตก (`-X`):** ปีกฝั่งห้องน้ำ, สโมสรนิสิต/ห้องสมุด, ระเบียงชั้น 2, ห้อง `C04` / `T05`
